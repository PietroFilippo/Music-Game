Three directions for the next musicgame UI

Static boards for a bilingual sight-reading and fretboard trainer. Each board keeps the current theme (dark surfaces, mint accent, system font, paper-style notation unless noted) and redesigns the same seven screens: home, quiz questions, answer feedback, lesson steps, results, stats and settings. Phone frames are 390 px wide; desktop frames are 1100 px scaled down. Open each board for the screens, captions and a tokens panel; see ../README.md for the brief and the recommendation.

A — Session

A practice-session flow: home opens on a Continue card, quizzes carry a round strip and timer ring in the header, feedback is a bottom sheet so Continue never moves, and settings are a sheet you can open mid-quiz. The neck is split into frets 0–6 and 7–12 so cells reach 43 × 40 px with no scrolling.

B — Map

A progress dashboard: sidebar with module rings on desktop, module cards unfolding into a path of topic nodes on mobile, round dots and a card-attached timer in quizzes, in-place feedback with an auto-advance fill on Continue, and a real stats dashboard. The neck scrolls at 44 px cells with zone chips.

C — Plain

One column, big targets, nothing nested: section headers instead of cards, 64 px rows, 56 px buttons, a bottom tab bar, and a grid of fret buttons under a context neck for fretboard questions. Notation is inverted to light ink on dark. Least to build, easiest one-handed.

Shared across all three
  • Settings leave the menu header; Practice becomes the primary action and Learn the secondary one; every module shows its progress and the next recommended topic.
  • Correct/wrong always combine colour, an icon and words; all text meets WCAG AA on the dark surfaces; every control is at least 44 px; focus rings are 2 px mint with a 3 px offset.
  • Music is kept as in the app: standard tuning with string 1 (high E) on top, naturals on string 1 at E0 F1 G3 A5 B7 C8 D10 E12, inlays at 3 5 7 9 and a double at 12, and written pitch an octave above sounding pitch (open string 1 = E5 in the top space; string 1 fret 7 = B5 above the staff).
  • Each board has small state toggles (correct / wrong, auto / manual) implemented with a few lines of vanilla JS; everything else is inline CSS and SVG and works offline.
